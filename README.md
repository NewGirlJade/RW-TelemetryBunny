## Rain World TelemetryLogger Mod

Mod for the game Rain World which runs quietly as the game is played. Logs player data while the "special" button is held. 

Writes to telemetry.log.jsonl

Probably not useful to most people. I'm using it to gather test data for use in porting a scaled-down version of the game to the Game Boy Advance while keeping the movement exactly the same.

The mod should be placed in [Rain world root directory]/RainWorld_Data/StreamingAssets/mods/telemetrylogger
Once the project is built you need to move TelemetryLogger.dll
