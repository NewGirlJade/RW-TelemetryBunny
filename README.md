## Rain World TelemetryLogger Mod

Mod for the game Rain World which runs quietly as the game is played. 

Press and release the "spec" button (default y) to toggle logging.

Writes to telemetry.log.jsonl in the rainworld game folder

Probably not useful to most people. I'm using it to gather test data for use in porting a scaled-down version of the game to the Game Boy Advance while keeping the movement as similar as possible.

The mod should be placed in [Rain world root directory]/RainWorld_Data/StreamingAssets/mods/telemetrylogger, and then it should just work when you run the build and boot up the game. Then you can start gathering data.
